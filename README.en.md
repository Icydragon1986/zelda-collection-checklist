# Zelda Collection Checklist

[Français](README.md) · [English](README.en.md)

A Windows and installable Web application for *The Legend of Zelda* collectors.

It tracks physical games, variants, special editions, consoles and amiibo from
North America, Europe/PAL and Japan. Collection data is stored locally by
default, can optionally be synced with end-to-end encryption, and the catalog
images work offline.

## Installation

Download the `setup.exe` file from the [latest release](https://github.com/Icydragon1986/zelda-collection-checklist/releases/latest).
The application will then automatically check for future updates.

### iPhone and iPad — no App Store required

Open the [installable Web version](https://icydragon1986.github.io/zelda-collection-checklist/) in Safari, tap **Share**, then **Add to Home Screen**. It will then open like an app and store the collection locally on the device.

The Web collection can also be exported or restored using the same JSON file as the Windows version. Optional private sync automatically keeps Windows and iPhone up to date. Configure it on Windows first, display the QR code, then scan it with the iPhone. The private pairing link can also be pasted manually if iOS opens the wrong screen.

Collection content is encrypted on the device before upload. The personal server never receives product names or a readable copy of the collection. Custom images remain local and are not synchronized.

## Main features

- separate lists by product category and region;
- cartridge/disc, manual, box and CIB tracking for games;
- boxed and individual amiibo tracking;
- enlarged cover and product image viewer;
- French and English interface;
- filters, statistics, missing-item reports and printable PDF checklist;
- ten automatic local backups plus JSON export and restoration;
- built-in form to report incorrect or missing catalog products;
- optional encrypted private sync with QR-code pairing;
- secure, signed automatic updates;
- installable Web version for iPhone, iPad, Android and desktop;

## Catalog contributions

Use the report button in the application or open a
[catalog report](https://github.com/Icydragon1986/zelda-collection-checklist/issues/new?template=catalog-report.yml).
Please include the product name, platform, region and a reliable source or photo.

For local development and catalog maintenance, see the
[quick catalog addition guide](docs/adding-catalog-items.md).
